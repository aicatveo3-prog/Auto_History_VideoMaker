# 에피소드 보완 리서치 규칙

한국사 쇼츠 에피소드를 만들거나 고칠 때는 **항상** 아래 절차를 따른다.
사용자가 역사 내용을 일일이 짚어 주지 않아도, 이 절차로 빠진 내용을 찾아 보완한다.

## 1. 데이터 기준
- 1차 참고 데이터: 한능검 빈출 선택지 사이트 (https://aicatveo3-prog.github.io/history-artifact/frequency.html)
  - 원본 저장소 `aicatveo3-prog/history-artifact` → `node tools/sync-source.mjs` 로 `data/hanneung.json` 동기화
  - 새 에피소드를 시작할 때, 또는 마지막 동기화가 2주 이상 지났으면 먼저 동기화한다.
- 용어 풀이: `data/glossary.json` / 개념 묶음: `data/concepts.json`
- 사이트 데이터에 없는 사실은 『삼국사기』 등 사료·교과서로 확인하고 `data/site-gaps.md` 에 적는다.

## 2. 절차
1. `episodes/<연도>_<주제>/topic.json` 작성: keywords, exclude(동음이의), kings, timeline, concepts, facts, terms
2. `node tools/related.mjs episodes/<폴더>` → `research.md` 생성
3. research.md 의 **반영 결정 표**를 채운다 (아래 기준)
4. 대본(`script.md`)에 반영하고, 대본 맨 아래 "보완 반영 내역"에 무엇을 어디에 넣었는지 적는다.

## 3. 반영 수준 기준
| 수준 | 기준 | 예 (녹읍 전쟁) |
|---|---|---|
| 본편 | ⭐빈출(5회↑)이면서 이야기의 원인·결과에 직접 필요 | 녹읍(14회), 김흠돌의 난(12회), 골품제(12회) |
| 자막 한 줄 | 빈출이지만 곁가지, 또는 용어 풀이 | 화백 회의(7회) |
| 화면 소재 | 영상으로 보여 줄 수 있는 유물·문서·장소 (시대가 맞는지 확인) | 신라 촌락 문서 → 장부 장면 |
| 고정댓글·설명란 | 시대를 넘나드는 비교, 퀴즈, 상식 | 직전법(17회)·토지 제도 흐름, 성덕 대왕 신종 |
| 다음 편 | 같은 시기의 독립 빈출 주제 | 왕오천축국전(10회), 9서당(10회) |
| 제외 | 동음이의, 시대 불일치, 근거 부족 | 정전 협정, 창경궁 정전 |

- 쇼츠 길이는 60초 안팎을 목표로 한다. 본편에 넣을 때는 다른 장면을 줄여 길이를 맞춘다.

## 4. 매번 확인할 체크리스트
- [ ] **용어**: 대본에 나오는 어려운 말(진골, 녹읍 등)은 모두 glossary 에 있고, 처음 나올 때 자막·내레이션으로 한 줄 풀이했다.
- [ ] **헷갈리는 짝**: 시험에서 함께 나오는 비교 대상(왕·제도·연도)을 정리했다.
- [ ] **앞뒤 흐름**: 원인(이전 사건)과 결과(이후 변화)를 최소 하나씩 넣었다.
- [ ] **사실 확인**: topic.json 의 facts 가 모두 ✅ 이거나, ⚠ 항목은 사료로 확인하고 site-gaps.md 에 적었다.
- [ ] **각색 표시**: 지어낸 대사·인물은 각색임을 대본에 표시했다. 연도·제도 내용은 바꾸지 않는다.
- [ ] **시대 고증**: 이미지 프롬프트의 복식·건물이 시대에 맞다. (통일신라 관리 = 복두+단령. 조선 갓·도포, 기모노, 변발 금지)
- [ ] **퀴즈**: 고정댓글 퀴즈는 사이트의 실제 선택지 문장을 활용했다.
- [ ] **시리즈 연결**: 다음 편 후보를 1~3개 적었다.
