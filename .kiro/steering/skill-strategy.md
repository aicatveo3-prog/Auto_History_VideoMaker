# 연출 스킬 사용 전략

설치된 스킬 (`.kiro/skills/`, 출처는 `ATTRIBUTION.md`):
- **각본:** `sw-premise-theme`, `sw-genre-anatomy`, `sw-story-structure`, `sw-character-conflict`, `sw-scene-craft`, `sw-dialogue`, `sw-korean-french-screenwriting`, `sw-workflow`(용어 참고용)
- **연출:** `cinematic-director`
- **프롬프트:** `image`(나노바나나), `video`(Veo·Kling·Seedance)

## 2. 겹치는 영역의 우선순위
1. **기획과 단계 관리는 이 저장소 규칙이 우선**한다 (`planning-framework.md`, `research-enrichment.md`). `sw-workflow`의 story-bible 단계 체계는 쓰지 않는다.
2. **역사적 사실은 research.md가 우선**한다. 어떤 스킬도 연도·제도·인물 관계를 바꾸지 못한다.
3. **컷 목록·동선·연속성 규칙은 `cinematic-director`가 정한다.** `video` 스킬은 그걸 받아 모델 문법으로 옮기기만 한다.
4. **최종 프롬프트 문법은 `image`/`video`가 정한다.** `cinematic-director`의 키프레임 초안은 `image` 스킬로 한 번 더 다듬는다.
5. 스킬 문서가 중국어·러시아어여도 **답변은 한국어**, 생성 프롬프트는 **영어**.

## 3. 감독 렌즈 규칙
- `cinematic-director` 규칙에 따라 **한 편에 렌즈는 1개만** 쓴다. 시대 차이(681/722/757)는 렌즈를 바꾸지 말고 **색 대본(color script)과 조명**으로만 표현한다.
- 렌즈를 쓰더라도 9:16 세로 화면에 맞게 조정한다. 아주 넓은 원경 대신 **깊이(앞-중간-뒤)**로 공간감을 만들고, 얼굴은 화면 위쪽 1/3에 둔다. 쇼츠 구조는 훅 → 변화 → 변화 → 결말.
- 실제 영화의 장면·대사·구도를 베끼지 않는다. 렌즈는 방법만 가져온다.

| 이야기 분위기 | 1순위 렌즈 | 대안 | 세로 쇼츠에서 조정할 점 |
|---|---|---|---|
| 감동 사극 (서민·가족) | `malick` (손·흙·역광 자연광) | `kurosawa` | 말릭의 긴 핸드헬드 표류는 AI가 얼굴을 흔들리게 만듦 → 느린 단일 이동으로 제한 |

| 궁중 의례·권력 과시 | `zhang_yimou` (단색 면, 대칭, 반복 패턴) | `kubrick` | 세로 대칭 구도 (계단, 회랑, 기둥 열) |

## 5. 쓸 때 주의
- **응답 크기를 요청에 맞춘다.** 프롬프트 하나를 요청하면 프롬프트 하나만 준다. 전체 패키지는 사용자가 "전부"라고 할 때만.
- **감정 단어 금지.** "슬퍼한다" 대신 "턱에 힘이 들어가고, 숨을 한 박자 멈춘다"처럼 몸의 행동으로 쓴다.
- **동작에는 끝 상태가 있어야 한다.** "고개를 돌린다"가 아니라 "고개를 돌려 옆얼굴이 들판을 향하면 멈춘다".
- **클립 하나에 동작 1개 + 카메라 이동 1개 + 환경 움직임 1개까지.**
- **같은 컷을 3번 실패하면** 프롬프트가 아니라 컷을 바꾼다 (짧게, 가깝게, 둘로 나누기, 반응 컷으로 대체).
- **부정어는 구체적인 물건 이름으로.** "현대 물건 금지"가 아니라 "no wristwatch, no plastic, no printed text, no zipper".
