# 에피소드 기획 규칙 (7단계)

사용자가 **키워드나 이야기 id 하나만** 주면, Kiro는 아래 7단계를 모두 수행해 `pitches.md`를 만들고 사용자의 선택을 기다린다.
대본(`script_<안>.md`)은 사용자가 안을 고른 뒤에만 쓴다.

## 기본 원칙
1. **영상 단위 = 이야기(갈등) 하나.** 키워드는 그 이야기 안의 시험 포인트로 들어간다.
2. **두 시청자를 함께 잡는다.** 모든 안에는 두 층이 있어야 한다.
   - 📖 **일반 시청자 층:** 갈등, 감정, 반전, 웃음. 용어를 몰라도 따라올 수 있어야 한다.
   - 📝 **수험생 층:** 용어 자막(처음 나올 때 한 줄 풀이), 연도 배지, 헷갈리는 짝, 마지막 4초 시험 카드, 고정댓글 퀴즈(사이트의 실제 선택지 문장 사용)
3. **분위기는 편마다 달라도 된다.** 다만 한 편 안에서는 하나로 통일한다.
4. **사실은 바꾸지 않는다.** 가상 인물과 대사는 각색으로 표시한다. 연도, 제도, 인물 관계는 사료와 데이터 기준.

## 7단계
| 단계 | 할 일 | 산출물 |
|---|---|---|
| ① 소재 | `node tools/new-episode.mjs <id·키워드>` 실행. 이야기 은행(data/stories.json)에 없으면 새 이야기를 제안하고 stories.json 에 추가 | episodes/<id>/ |
| ② 갈등 | 누가 누구와 왜 부딪히는지 3줄로 정리 | pitches.md ② |
| ③ 핵심 두 줄 | 📖 이야기 한 줄 + 📝 시험 한 줄. 이 두 줄에 도움이 안 되는 내용은 본편에서 뺀다 | pitches.md ③ |
| ④ 시점 기획안 | 아래 시점 메뉴에서 **주제에 맞는 안을 모두**(최소 4개) 만든다. 각 안: 분위기, 주인공(3명 이하 권장), 줄거리, 📖/📝 포인트, 60초 장면표(시간·화면·대사·자막), 제작 난도, 위험 | pitches.md ④ |
| ⑤ 60초 구조 | 훅(0~3초) → 설정(~15) → 갈등(~30) → 전환(~45) → 결과·반전(~53) → 시험 카드(~60) + 반복 재생 연결 | 안별 장면표 |
| ⑥ 보완 리서치 | research-enrichment.md 절차. topic.json 에 exclude·facts·terms·concepts 채우고 related.mjs 재실행 | research.md, pitches.md ⑥ |
| ⑦ 제작 가능성·점수 | 아래 기준으로 안별 점수표 + 추천 조합 | pitches.md ⑦ |

## 시점 메뉴
| 유형 | 설명 | 잘 맞는 주제 |
|---|---|---|
| A. 서민 | 그 시대 평범한 사람의 눈 | 제도·수취·생활사 |
| B. 악역·반대편 | 패자, 귀족, 침략자 등 반대편 시점의 반전극 | 개혁, 전쟁 |
| C. 권력자 대결 | 왕 vs 신하, 영웅 vs 영웅 | 정변, 개혁, 전쟁 |
| D. 유물 화자 | 유물·문화유산이 1인칭으로 회상 (채널 브랜드: "유물로 배우는 한국사") | 문화유산이 있는 주제 |
| E. 현대 비유 | 회사, 학교, 단톡방 등 현대 상황으로 바꿔 설명. 비유마다 실제 용어 자막 필수 | 제도, 기구, 경제 |
| F. 뉴스 | 고정 앵커가 진행하는 「서라벌/개경/한양 9시 뉴스」 | 모든 주제 (시리즈 포맷) |
| G. 선택 게임 | "당신이 ○○라면?" 선택지를 고르고 실제 역사 공개 | 결정의 순간이 있는 주제 |
| H. 기타 | 브이로그, 토론 예능, 면접, 리얼리티 패러디 등 주제에 맞게 자유롭게 | — |

## 분위기 메뉴
정통 사극 · 감동 · 스릴러·느와르 · 복수극 · 전쟁 · 코믹 · 오피스 코미디 · 뉴스·예능 패러디 · 서정 다큐 · 레트로 감성

## 점수 기준 (각 1~5)
훅 강도 / 감정이입 / 시험 연결 / 제작 쉬움 / 시리즈성 → 합계 25점

## 제작 가능성 기준 (AI 이미지 → 이미지 투 비디오)
- 주요 인물 **3명 이하** 권장 (캐릭터 시트를 만들고 모든 장면에 레퍼런스로 첨부)
- 장소 **3곳 이하** 권장, 컷 하나는 **4~8초**
- 대사 컷 **5개 이하** 권장 (입 모양 맞추기 작업량)
- 고정 캐릭터(두지, 김 대아찬 가문, 뉴스 앵커)와 고정 세트(뉴스 스튜디오)는 `characters/` 에 두고 재사용
- 대규모 전투 장면은 지도, 소수 인물, 실루엣으로 대체

## 주의 주제
- 근현대 실존 인물(대통령, 정치인)은 얼굴 재현 대신 사진 자료·실루엣·이름 카드
- 학살, 항쟁, 피해자 주제는 코믹 톤 금지, 선정적 묘사 금지
- 설화(에밀레종 전설 등)는 사실처럼 묘사하지 않기

## 결과 보고 형식
사용자에게는 안별 한 줄 요약 + 점수표 + 추천 조합을 보여 주고, **어떤 안으로 대본을 쓸지** 묻는다.
