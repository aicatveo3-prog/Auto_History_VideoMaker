## 1. 모션그래픽 디자인 원칙

### 핵심 아이디어: 쌀이 어디로 가나 (흐름도)
영상 내내 같은 **흐름도** 하나가 네 번 모양을 바꾸며 나옵니다. 이것만 봐도 이야기가 이해되게 만드는 게 목표예요.

```
        [나라 👑]
            
 [귀족 🎩] ←── [백성 🌾]      ① 녹읍: 쌀과 일이 귀족에게
 [귀족 🎩] ─╳─ [백성 🌾]      ② 녹읍 폐지: 화살표가 끊김
 [나라 👑] ←── [백성 🌾]      ③ 정전: 땅은 백성에게, 쌀은 나라로
 [귀족 🎩] ←── [백성 🌾] (붉게) ④ 녹읍 부활: 다시 귀족에게
```

### 고정 요소: 연표 바
화면 위쪽에 얇은 연표 줄이 늘 있고, 붓으로 찍은 점이 지금 시점을 가리킵니다.
`681 ── 689 ── 722 ── 757` · 시대가 바뀔 때 점이 미끄러져 이동해요.

### 스타일
| 항목 | 정의 |
|---|---|
| 느낌 | **먹과 한지.** 붓으로 그린 선과 아이콘, 붉은 인주 도장. 반짝이거나 튀는 효과는 쓰지 않아요 (말릭 화면과 어울리게) |
| 색 | 먹 `#2A2622` · 한지 `#E9E3D4` · 귀족·녹읍 인주색 `#C8412B` · 백성·정전 녹색 `#4C7A6B` · 722년 금빛 `#D9A441` |
| 글꼴 | 용어·제목 Noto Serif KR Bold / 설명 Pretendard Bold |
| 글자 크기 | 용어 96px, 설명 56px, 연표 32px (1080×1920 기준) |
| 움직임 | 선은 붓으로 그려지듯 0.4초 / 글자는 붓 쓸기 닦아내기 0.3초 / 도장은 120%→100%로 찍히며 2프레임 흔들림 / 아이콘은 화살표를 따라 1초 이동 |

### 규칙
1. **얼굴과 손을 가리지 않는다.** 흐름도는 하늘(화면 위쪽 절반)에 띄워요. 말릭 구도가 위 절반을 하늘로 비워 둔 덕분에 자리가 있어요.
2. **한 번에 그래픽 요소는 2개까지** (연표 바 제외)
3. **글자는 1.5초 이상** 머물러야 읽혀요. 한 줄 12자 이내.
4. **감정 장면(0:45~0:49)에는 그래픽을 하나도 넣지 않는다.** 연표 바까지 잠깐 사라져요.
5. 안전 영역: 아래 400px, 오른쪽 140px 비우기

## 4. 그래픽 소스 만들기

### 먹선 아이콘 6개 (나노바나나로 한 장에 생성 → 잘라 쓰기)
```
Create a set of six simple icons drawn with a single black ink brush on plain light beige hanji paper, arranged in a 3 by 2 grid with generous space between them: a straw rice sack, a simple standing peasant figure, an aristocrat's black winged hat, a small royal crown, a raised wooden granary on stilts, and a small square seal stamp. Loose confident brush strokes like traditional Korean ink painting, slightly dry brush texture at the edges, no colour except black ink, no text, no frames.
```
배경을 지우고(누끼) 투명 PNG로 써요. 귀족·녹읍 쪽은 인주색, 백성·정전 쪽은 녹색으로 칠해서 써요.

### 붓 질감 소스
- 붓 획(화살표, ✕, 밑줄)은 무료 "ink brush stroke" 소스나 CapCut 기본 붓 효과를 써도 돼요.
- 한지 질감 카드 배경은 사이트 색(`#E9E3D4`)에 종이 질감을 25% 정도 겹쳐요.

## 5. 편집 도구별 방법
| 도구 | 추천 상황 | 방법 |
|---|---|---|
| **CapCut** (가장 쉬움) | 처음 몇 편 | 아이콘 PNG를 오버레이로 올리고 키프레임으로 이동 / 화살표는 "마스크 → 선형"으로 그려지는 효과 / 글자는 "붓글씨" 등장 애니메이션 / 흐름도는 한 번 만들어 **템플릿으로 저장**하고 매 편 재사용 |
| After Effects | 품질을 높이고 싶을 때 | 화살표 = Trim Paths, 붓 질감 = Turbulent Displace, 흐름도는 프리컴프로 만들어 4가지 상태로 키프레임 |
| Remotion (코드) | 나중에 자동화할 때 | 흐름도·연표 바·카드를 컴포넌트로 만들고, 컷별 제작표를 JSON으로 넣으면 자동 합성. 이 저장소의 자동화 목표와 연결 |

**순서:** 실사 컷 편집과 녹음을 먼저 맞추고 → 연표 바 → 흐름도 → 용어 카드 → 자막 순서로 얹어요.
