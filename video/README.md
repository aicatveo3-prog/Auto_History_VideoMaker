## 보는 법 / 영상으로 저장하는 법
1. HTML 파일을 내려받아 **Chrome**에서 엽니다 (인터넷 연결 필요: 글꼴을 불러와요).
2. **▶ 재생**으로 미리 보고, 막대로 원하는 시간으로 이동할 수 있어요. 주소 뒤에 `?t=40`을 붙이면 40초 장면부터 열려요.
3. **● 녹화해서 영상 저장**을 누르면 60초 동안 실시간으로 녹화한 뒤 파일이 자동으로 다운로드돼요. 녹화 중에는 탭을 앞에 띄워 두세요.
   - 최신 Chrome은 `.mp4`, 그 외에는 `.webm`으로 저장돼요. YouTube는 둘 다 올릴 수 있어요.

## 구성
- 실사 컷 대신 코드로 그린 먹·한지풍 화면 (논, 귀족 행렬, 고을 지도와 도장, 손, 문서, 창가)
- 목소리 대신 자막 (핵심어 녹읍·귀족은 붉게, 정전·백성은 녹색으로)
- 모션그래픽: 연표 줄, "쌀은 어디로 가나" 흐름도(4단계), 용어 카드와 도장, 마지막 정리 카드
- 장면표와 자막은 파일 안의 `SCENES`, `SUBS` 배열에서 고칠 수 있어요.

나중에 Veo 실사 클립이 생기면, 각 장면 함수를 영상 재생으로 바꾸거나 Remotion으로 옮겨 실사 + 같은 그래픽으로 합성할 수 있어요.
