## 운영 방식 두 가지 (골라 주세요)

### 방식 1. 시즌 순서대로 (연재형)
시대순으로 이어지고, 고정 캐릭터가 대를 이어 등장해요. 구독자가 정주행하기 좋아요.

| 시즌 | 주제 | 편수 |
|---|---|---|
| S0 | 선사·초기 국가 (특별편) | 3 |
| S1 | 신라 권력 전쟁 | 7 |
| S2 | 삼국 쟁패 | 12 |
| S3 | 후삼국과 고려 건국 | 5 |
| S4 | 고려: 외침과 무신 | 12 |
| S5 | 조선 전기: 왕과 신하 | 8 |
| S6 | 조선 중·후기: 전쟁과 개혁 | 10 |
| S7 | 개화기: 흔들리는 나라 | 10 |
| S8 | 일제강점기: 저항의 기록 | 13 |

**S1 추천 순서:** ① 골품제와 6두품의 한(세계관 소개) → ② 신문왕의 숙청 → ③ **녹읍 전쟁(파일럿)** → ④ 원효 vs 의상 → ⑤ 혜초 → ⑥ 장보고 → ⑦ 하대 반란 릴레이 → S3 후삼국으로 연결
